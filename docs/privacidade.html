Política de Privacidade — Máquina de Cortes

Última atualização: 18 de novembro de 2026

A Máquina de Cortes é um programa que roda no computador do próprio usuário. Não existe servidor da Máquina de Cortes: nenhum dado do usuário é enviado para nós.

Dados do Google / YouTube que o programa acessa

Somente se o usuário clicar em "Conectar YouTube" e autorizar pelo login oficial do Google, o programa pede:

  • youtube.upload — para enviar ao canal do usuário os cortes que ele escolher publicar;
  • youtube.readonly — para ler o nome do canal e as estatísticas (visualizações, curtidas e comentários) dos vídeos do próprio usuário, usadas para melhorar a escolha dos próximos cortes.

O programa não lê, altera nem apaga outros vídeos, comentários, mensagens ou dados da conta.

Onde os dados ficam

A autorização do Google e as estatísticas ficam salvas apenas no computador do usuário (pasta Documentos\MaquinaCortes). Elas não são vendidas, compartilhadas nem enviadas a terceiros, e não são usadas para publicidade.

Para escolher os melhores momentos e escrever títulos, o texto transcrito dos vídeos (e, no aprendizado, os títulos e estatísticas dos Shorts do próprio usuário) é enviado à IA escolhida pelo usuário — a API da Anthropic (Claude) ou o Claude Code da conta do próprio usuário. Nenhum dado do Google é usado para treinar modelos de IA.

Como remover o acesso

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions e apagar o arquivo youtube_token.json da pasta do programa.

O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.
